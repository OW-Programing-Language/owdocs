The Ow Language

A tiny, YAML-shaped programming language with two ways to run: an in-process interpreter for instant feedback, and a real LLVM/clang pipeline that produces native .exe files.

Download Ow IDE Install guide

Overview

Ow looks like YAML, but it's not configuration — it's code. Statements are keys with values, and blocks are made of indentation, just like YAML. Programs always have a main: block. You can also define fn functions at the top level.

Hello, Ow:

main:
  print: "hello, ow!"

Two-space indentation, colons everywhere, no curly braces. If you can write YAML, you can write Ow.

Install & Run

What you need

  • Java 17+ — required to run the IDE / compiler. Get it from Adoptium.
  • clang (optional) — only if you want to build native .exe files. Install LLVM and make sure clang is on your PATH.

Launch the IDE

Download OwIDE.jar

From the project's target folder, double-click Run-OwIDE.bat, or run from a terminal:

java -jar OwIDE.jar

Run a single file from the command line

# interpret a .ow file (no clang needed)
java -cp OwIDE.jar dev.oreo.Main --run hello.ow

# build a native .exe via LLVM/clang
java -cp OwIDE.jar dev.oreo.Main hello.ow hello.exe

Your first program

Create a file hello.ow with this content:

main:
  set name: "world"
  print: "hello, " + name

In the IDE, hit Run ▶. You should see:

hello, world
Two ways to run: Run ▶ uses the interpreter (fast, no extra tools) — perfect while you're writing code. Build .exe compiles via LLVM/clang into a real Windows executable you can ship.

Using the IDE

The Ow IDE is a small Swing app with everything you need to write, run, and version your code.

Layout

  • Left — Project tree: double-click any .ow to open it in a tab. Right-click a folder to New File, New Folder, Rename, or Delete.
  • Center — Editor tabs: open as many files as you want. Tabs show filename.ow * when there are unsaved changes.
  • Bottom — Output: all program output, compiler errors, and Git command output stream here in real time.

The YAML shape

Ow uses three rules to give it its YAML look:

  1. Statements are keyword: value. Like set x: 5 or print: x.
  2. Blocks are indented by 2 spaces. Tabs are not allowed; the indent level must be a multiple of 2.
  3. Top-level items are either a main: block (required, exactly one) or one or more fn name(args): blocks.
# one main block, optional fn declarations
fn double(n):
  return: n * 2

main:
  print: double(21)
Indentation must be exactly 2 spaces per level. 4 spaces, 1 tab, or odd numbers will give you a Lexer error.

Comments

Anything after # on a line is a comment. They're allowed anywhere except inside string literals.

# this whole line is a comment
main:
  set x: 42     # trailing comments work too
  print: "# this is NOT a comment, it's inside a string"

Variables — set

Use set to create or update a variable. The first set declares it; later sets reassign it.

main:
  set x: 5            # declare
  set x: x + 1        # reassign
  print: x              # 6

Variable names are letters / digits / _, and must start with a letter or _.

Scope: in v1, all variables live in the block they're set in. Function parameters and locals stay inside the function. There are no globals.

Printing — print

print writes its expression to standard output, followed by a newline.

main:
  print: 42
  print: "hello"
  print: 1 + 2 * 3
  print: "answer = " + 42

Output:

42
hello
7
answer = 42

Numbers & strings

Integers

Whole numbers like 0, 1, 2025. Negative numbers are written as 0 - n for now.

Strings

Double-quoted text. Supported escapes:

EscapeMeaning
\nnewline
\ttab
\"literal double-quote
\\backslash
main:
  print: "line one\nline two"
  print: "she said \"hi\""

String + value

The + operator concatenates when either side is a string. Numbers are stringified automatically.

main:
  set name: "ow"
  set n: 3
  print: "hi " + name + ", number " + n
String concatenation works in Run (interpreter) but the LLVM Build .exe backend only supports plain "text" printing for now — no + on strings.

Operators

Arithmetic

OpMeaningExample
+add (or string concat)1 + 2 → 3
-subtract5 - 1 → 4
*multiply3 * 4 → 12
/integer divide7 / 2 → 3

Comparison

Comparisons evaluate to 1 (true) or 0 (false). Useful inside if and while.

OpMeaning
==equal
!=not equal
<  >less / greater than
<=  >=less / greater or equal

Precedence

  1. * / bind tightest
  2. then + -
  3. then comparisons

Use parentheses to override: (a + b) * c.

If / Else

The condition follows the colon, and the body is indented by two spaces. else: is optional and lines up with if:.

main:
  set n: 7
  if: n > 5
    print: "big"
  else:
    print: "small"

Nested ifs

main:
  set n: 0
  if: n > 0
    print: "positive"
  else:
    if: n == 0
      print: "zero"
    else:
      print: "negative"

Conditions can be a comparison, a number (non-zero is truthy), or a function call returning a number.

While loops

main:
  set i: 0
  while: i < 5
    print: i
    set i: i + 1

Output:

0
1
2
3
4
There is no break or continue in v1 — express the same logic with a flag variable, or refactor with an early return: inside a function.

Functions

Declaring

Functions go at the top level (outside main:). A function takes any number of integer parameters and returns an integer with return:.

fn add(a, b):
  return: a + b

main:
  print: add(3, 4)   # 7

Calling

Two ways to call:

  • As an expression — anywhere a value is expected: set s: add(3, 4)
  • As a statement — to discard the result: call: add(3, 4)

Recursion

fn fact(n):
  if: n <= 1
    return: 1
  else:
    return: n * fact(n - 1)

main:
  print: fact(6)   # 720
Function arguments and return values are integers only. You can use strings inside main:, but you can't pass them through functions yet.

Example programs

FizzBuzz

main:
  set i: 1
  while: i <= 15
    if: (i / 3) * 3 == i
      if: (i / 5) * 5 == i
        print: "FizzBuzz"
      else:
        print: "Fizz"
    else:
      if: (i / 5) * 5 == i
        print: "Buzz"
      else:
        print: i
    set i: i + 1

Power function

fn pow(base, exp):
  set result: 1
  while: exp > 0
    set result: result * base
    set exp: exp - 1
  return: result

main:
  print: pow(2, 10)    # 1024
  print: pow(3, 4)     # 81

GCD (Euclid)

fn gcd(a, b):
  while: b != 0
    set t: b
    set b: a - (a / b) * b
    set a: t
  return: a

main:
  print: gcd(462, 1071)   # 21

Sum 1..n

fn sumTo(n):
  set s: 0
  set i: 1
  while: i <= n
    set s: s + i
    set i: i + 1
  return: s

main:
  print: "sum 1..100 = " + sumTo(100)

Common errors & fixes

"Indentation must be a multiple of 2 spaces"

You used 1 / 3 / 4 spaces or a tab. Switch to 2-space indents.

"Expected statement (set/print/if/while/return/call)"

Every line inside a block has to start with one of those keywords. Bare expressions like x + 1 are not statements.

"Undefined variable: x"

You read x before set x: …. Variables can't be used before their first set.

"Unknown function: foo"

Either you misspelled the name, or you forgot the fn foo(...): declaration above main:.

"Build needs clang on PATH"

Only matters for Build .exe. Run ▶ still works without clang. To get clang, install LLVM and re-open the IDE.

Limits & quirks

  • Only one main: block per file. Multiple files / imports are not supported yet.
  • No arrays, dicts, or objects yet. Variables are integers or strings.
  • No break / continue in loops.
  • No boolean type. Use 0 / non-zero, or comparisons.
  • Integer division only — 7 / 2 is 3, not 3.5.
  • No standard library — only print and arithmetic.
  • Run (interpreter) supports every feature. Build .exe doesn't yet support string concat or strings through functions.

Cheat sheet

# literals
42            # int
"hello"       # string with \n \t \" \\

# declare / reassign
set name: value

# print
print: expr

# if / else
if: cond
  body
else:
  body

# while
while: cond
  body

# function definition (top level)
fn name(a, b):
  return: expr

# function call (expression or statement)
set r: name(1, 2)
call: name(1, 2)

# operators (high → low precedence)
*  /        # multiply, integer divide
+  -        # add, subtract (or string concat)
== !=       # equality
< > <= >=   # ordering
