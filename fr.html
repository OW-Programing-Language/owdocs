Le Langage Ow

Un petit langage de programmation au format YAML, avec deux façons d'exécuter votre code : un interpréteur intégré pour un retour instantané, et une véritable chaîne LLVM/clang qui produit des exécutables .exe natifs.

Télécharger Ow IDE Guide d'installation

Aperçu

Ow ressemble à du YAML, mais ce n'est pas de la configuration — c'est du code. Les instructions sont des clés associées à des valeurs, et les blocs sont définis par l'indentation, exactement comme en YAML. Les programmes contiennent toujours un bloc main:. Vous pouvez aussi définir des fonctions fn au niveau supérieur.

Hello, Ow :

main:
  print: "hello, ow!"

Indentation de deux espaces, deux-points partout, pas d'accolades. Si vous savez écrire du YAML, vous savez écrire du Ow.

Installation et exécution

Ce qu'il vous faut

  • Java 17+ — requis pour exécuter l'IDE / le compilateur. Téléchargez-le sur Adoptium.
  • clang (optionnel) — uniquement si vous souhaitez compiler des fichiers .exe natifs. Installez LLVM et assurez-vous que clang soit dans votre PATH.

Lancer l'IDE

Télécharger OwIDE.jar

Depuis le dossier target du projet, double-cliquez sur Run-OwIDE.bat, ou exécutez depuis un terminal :

java -jar OwIDE.jar

Exécuter un fichier en ligne de commande

# interprète un fichier .ow (clang non requis)
java -cp OwIDE.jar dev.oreo.Main --run hello.ow

# compile un .exe natif via LLVM/clang
java -cp OwIDE.jar dev.oreo.Main hello.ow hello.exe

Votre premier programme

Créez un fichier hello.ow avec ce contenu :

main:
  set name: "world"
  print: "hello, " + name

Dans l'IDE, cliquez sur Run ▶. Vous devriez voir :

hello, world
Deux façons d'exécuter : Run ▶ utilise l'interpréteur (rapide, sans outils supplémentaires) — parfait pendant que vous écrivez du code. Build .exe compile via LLVM/clang en un véritable exécutable Windows que vous pouvez distribuer.

Utiliser l'IDE

L'IDE Ow est une petite application Swing qui contient tout ce qu'il faut pour écrire, exécuter et versionner votre code.

Disposition

  • Gauche — Arborescence du projet : double-cliquez sur n'importe quel fichier .ow pour l'ouvrir dans un onglet. Clic droit sur un dossier pour Nouveau fichier, Nouveau dossier, Renommer ou Supprimer.
  • Centre — Onglets de l'éditeur : ouvrez autant de fichiers que vous voulez. Les onglets affichent fichier.ow * en cas de modifications non sauvegardées.
  • Bas — Sortie : toute la sortie du programme, les erreurs du compilateur et la sortie des commandes Git apparaissent ici en temps réel.

La forme YAML

Ow s'appuie sur trois règles pour son apparence YAML :

  1. Les instructions sont des mot-clé: valeur. Comme set x: 5 ou print: x.
  2. Les blocs sont indentés de 2 espaces. Les tabulations ne sont pas autorisées ; le niveau d'indentation doit être un multiple de 2.
  3. Les éléments du niveau supérieur sont soit un bloc main: (requis, exactement un) soit un ou plusieurs blocs fn nom(args):.
# un seul bloc main, déclarations fn optionnelles
fn double(n):
  return: n * 2

main:
  print: double(21)
L'indentation doit faire exactement 2 espaces par niveau. 4 espaces, 1 tabulation ou un nombre impair provoqueront une erreur du Lexer.

Commentaires

Tout ce qui suit # sur une ligne est un commentaire. Ils sont autorisés partout sauf à l'intérieur d'une chaîne littérale.

# cette ligne entière est un commentaire
main:
  set x: 42     # un commentaire en fin de ligne fonctionne aussi
  print: "# ceci N'EST PAS un commentaire, c'est dans une chaîne"

Variables — set

Utilisez set pour créer ou mettre à jour une variable. Le premier set la déclare ; les set suivants la réassignent.

main:
  set x: 5            # déclaration
  set x: x + 1        # réassignation
  print: x              # 6

Les noms de variables se composent de lettres / chiffres / _, et doivent commencer par une lettre ou _.

Portée : en v1, toutes les variables existent dans le bloc où elles sont définies. Les paramètres et variables locales d'une fonction restent à l'intérieur de la fonction. Il n'y a pas de variables globales.

Affichage — print

print écrit son expression sur la sortie standard, suivie d'un saut de ligne.

main:
  print: 42
  print: "hello"
  print: 1 + 2 * 3
  print: "answer = " + 42

Sortie :

42
hello
7
answer = 42

Nombres et chaînes

Entiers

Des nombres entiers comme 0, 1, 2025. Les nombres négatifs s'écrivent 0 - n pour le moment.

Chaînes

Du texte entre guillemets doubles. Échappements supportés :

ÉchappementSignification
\nsaut de ligne
\ttabulation
\"guillemet littéral
\\barre oblique inverse
main:
  print: "ligne un\nligne deux"
  print: "elle a dit \"salut\""

Chaîne + valeur

L'opérateur + concatène lorsque l'un des deux côtés est une chaîne. Les nombres sont convertis automatiquement en chaîne.

main:
  set name: "ow"
  set n: 3
  print: "salut " + name + ", numéro " + n
La concaténation de chaînes fonctionne avec Run (interpréteur), mais le backend LLVM Build .exe ne supporte pour l'instant que l'affichage simple de "texte" — sans + sur les chaînes.

Opérateurs

Arithmétique

OpSignificationExemple

-soustraction5 - 1 → 4
*multiplication3 * 4 → 12

Comparaison

Les comparaisons donnent 1 (vrai) ou 0 (faux). Très utiles dans if et while.

OpSignification
==égal
!=différent
<  >strictement inférieur / supérieur
<=  >=inférieur ou égal / supérieur ou égal

Précédence

  1. * / ont la priorité la plus forte
  2. puis + -
  3. puis les comparaisons

Utilisez des parenthèses pour modifier l'ordre : (a + b) * c.

Si / Sinon

La condition suit le deux-points, et le corps est indenté de deux espaces. else: est optionnel et s'aligne avec if:.

main:
  set n: 7
  if: n > 5
    print: "grand"
  else:
    print: "petit"

Conditions imbriquées

main:
  set n: 0
  if: n > 0
    print: "positif"
  else:
    if: n == 0
      print: "zéro"
    else:
      print: "négatif"

Les conditions peuvent être une comparaison, un nombre (non-zéro = vrai), ou un appel de fonction qui retourne un nombre.

Boucles While

main:
  set i: 0
  while: i < 5
    print: i
    set i: i + 1

Sortie :

0
1
2
3
4
Il n'y a pas de break ou continue en v1 — exprimez la même logique avec une variable de drapeau, ou refactorez avec un return: anticipé dans une fonction.

Fonctions

Déclaration

Les fonctions se placent au niveau supérieur (en dehors de main:). Une fonction prend un nombre quelconque de paramètres entiers et retourne un entier avec return:.

fn add(a, b):
  return: a + b

main:
  print: add(3, 4)   # 7

Appel

Deux façons d'appeler une fonction :

  • En tant qu'expression — partout où une valeur est attendue : set s: add(3, 4)
  • En tant qu'instruction — pour ignorer le résultat : call: add(3, 4)

Récursion

fn fact(n):
  if: n <= 1
    return: 1
  else:
    return: n * fact(n - 1)

main:
  print: fact(6)   # 720
Les arguments et valeurs de retour des fonctions sont uniquement des entiers. Vous pouvez utiliser des chaînes dans main:, mais on ne peut pas encore les passer à travers des fonctions.

Exemples de programmes

FizzBuzz

main:
  set i: 1
  while: i <= 15
    if: (i / 3) * 3 == i
      if: (i / 5) * 5 == i
        print: "FizzBuzz"
      else:
        print: "Fizz"
    else:
      if: (i / 5) * 5 == i
        print: "Buzz"
      else:
        print: i
    set i: i + 1

Fonction puissance

fn pow(base, exp):
  set result: 1
  while: exp > 0
    set result: result * base
    set exp: exp - 1
  return: result

main:
  print: pow(2, 10)    # 1024
  print: pow(3, 4)     # 81

PGCD (Euclide)

fn gcd(a, b):
  while: b != 0
    set t: b
    set b: a - (a / b) * b
    set a: t
  return: a

main:
  print: gcd(462, 1071)   # 21

Somme 1..n

fn sumTo(n):
  set s: 0
  set i: 1
  while: i <= n
    set s: s + i
    set i: i + 1
  return: s

main:
  print: "somme 1..100 = " + sumTo(100)

Erreurs courantes et solutions

« Indentation must be a multiple of 2 spaces »

Vous avez utilisé 1 / 3 / 4 espaces ou une tabulation. Passez à des indentations de 2 espaces.

« Expected statement (set/print/if/while/return/call) »

Chaque ligne d'un bloc doit commencer par l'un de ces mots-clés. Les expressions seules comme x + 1 ne sont pas des instructions.

« Undefined variable: x »

Vous avez lu x avant son premier set x: …. Une variable ne peut pas être utilisée avant sa première affectation.

« Unknown function: foo »

Soit le nom est mal orthographié, soit il manque la déclaration fn foo(...): au-dessus de main:.

« Build needs clang on PATH »

Concerne uniquement Build .exe. Run ▶ fonctionne sans clang. Pour obtenir clang, installez LLVM et redémarrez l'IDE.

Limitations et particularités

  • Un seul bloc main: par fichier. Plusieurs fichiers / imports ne sont pas encore supportés.
  • Pas encore de tableaux, dictionnaires ou objets. Les variables sont des entiers ou des chaînes.
  • Pas de break / continue dans les boucles.
  • Pas de type booléen. Utilisez 0 / non-zéro, ou des comparaisons.
  • Division entière uniquement — 7 / 2 vaut 3, pas 3.5.
  • Pas de bibliothèque standard — uniquement print et l'arithmétique.
  • Run (interpréteur) supporte toutes les fonctionnalités. Build .exe ne supporte pas encore la concaténation de chaînes ni les chaînes à travers les fonctions.

Aide-mémoire

# littéraux
42            # entier
"hello"       # chaîne avec \n \t \" \\

# déclaration / réassignation
set nom: valeur

# affichage
print: expr

# si / sinon
if: cond
  corps
else:
  corps

# tant que
while: cond
  corps

# définition de fonction (niveau supérieur)
fn nom(a, b):
  return: expr

# appel de fonction (expression ou instruction)
set r: nom(1, 2)
call: nom(1, 2)

# opérateurs (priorité forte → faible)
*  /        # multiplication, division entière
+  -        # addition, soustraction (ou concaténation de chaînes)
== !=       # égalité
< > <= >=   # comparaison
